# Agathin Kural — Psychology Counselling Website

A responsive React + Bootstrap 5 starter website. It uses Bootstrap classes and components; no custom CSS stylesheet is included.

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open the extracted `psychology-website` folder in VS Code.
3. Open the terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Production build
```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Before client delivery
- Replace `contact@example.com` in `src/App.jsx` with the approved contact email.
- Confirm the service descriptions and FAQs with the client.
- Replace the external Unsplash image with a properly licensed image approved for the business.
- The current appointment buttons only navigate to the contact section; no booking system is implemented.
- If adding a form or booking service, configure it securely and update the privacy notice to reflect actual data handling.
- Only publish real, approved testimonials and verified professional qualifications.

## Styling
Bootstrap CSS, Bootstrap JavaScript, and Bootstrap Icons are imported from installed packages in `src/main.jsx`. No `App.css` or custom stylesheet is used.
